# 默认封面与头像图

请在此目录放置以下图片文件，用于活动/搭子默认头图及详情测试图：

- `activity-default.png` - 活动默认封面、默认头像占位
- `activity-sport.png` - 运动类活动
- `activity-food.png` - 美食类活动
- `activity-study.png` - 学习类活动
- `activity-party.png` - 娱乐/派对类活动
- `partner-default.png` - 搭子默认封面
- `partner-food.png`、`partner-sport.png`、`partner-study.png` - 各类型搭子

若文件不存在，接口将返回 404，前端会显示占位失败。建议使用统一风格的插画或照片（如 1:1 或 4:3）。
