# AI + 社交 产品需求文档

**项目名称**：PopSoda（拟）
**日期**：2026-03-05
**版本**：V1.0

---

## 一、产品定位

### 1.1 核心定位
**让年轻人因兴趣相遇，因圈子相识** - 融合兴趣社交与熟人社交，AI 加持智能匹配的下一代社交平台。

### 1.2 竞品参考
- **泡泡苏打**：兴趣社交、找搭子、活动、基于 LBS
- **脉脉**：职场熟人社交、同事圈、校友圈

---

## 二、目标用户

- 18-35 岁都市青年
- 追求兴趣社交、线下活动
- 有职场/校友圈子需求
- 喜欢 AI 带来的智能体验

---

## 三、核心功能

### 3.1 搭子模块（核心）

| 功能 | 说明 |
|------|------|
| 发布搭子 | 标题 + 描述 + 兴趣标签 + 范围 + 人数 |
| 应征加入 | 发送应征消息 |
| 范围限定 | 全部 / 仅同事 / 仅校友 / 附近 |
| AI 辅助发布 | 输入关键词 → AI 生成文案 |
| AI 应征助手 | 一键生成应征话术 |
| 智能匹配 | AI 根据兴趣/位置推荐 |
| 匹配度显示 | "兴趣匹配度 88%" |

### 3.2 活动模块（核心）

| 功能 | 说明 |
|------|------|
| 发布活动 | 标题 + 时间 + 地点 + 人数 + 范围 |
| 报名参加 | 报名/签到 |
| 附近活动 | LBS 推荐 |
| AI 活动文案 | 输入要点 → AI 生成描述 |
| AI 活动推荐 | 根据兴趣智能推荐 |

### 3.3 社交圈子

| 圈子 | 认证方式 |
|------|----------|
| 同事圈 | 企业名称 + 邀请码 |
| 校友圈 | 学校名称 + 邀请码 |

### 3.4 AI 能力（核心亮点）

```
┌─────────────────────────────────────────────┐
│              AI 能力矩阵                      │
├─────────────────────────────────────────────┤
│ 🏷️ 兴趣标签建议    根据行为自动推荐兴趣标签    │
│ ✍️ AI 文案生成     活动/搭子描述自动生成      │
│ 💬 AI 应征话术     一键生成搭子应征消息       │
│ 🔍 AI 智能搜索     自然语言找搭子/活动       │
│ 🎯 AI 智能推荐     个性化推荐算法            │
│ 📊 AI 匹配度       显示兴趣/圈子匹配程度      │
│ 🛡️ AI 内容审核    自动识别敏感内容          │
│ 💡 破冰话题        根据共同兴趣推荐聊天话题   │
└─────────────────────────────────────────────┘
```

## 四、AI 原生首页设计（颠覆性）

### 4.1 传统 vs AI-Native

| 传统首页 | AI-Native 首页 |
|----------|----------------|
| 分类 Tab + 瀑布流 | AI 对话 + 智能推荐 |
| 用户主动搜索 | AI 理解需求，主动推荐 |
| 固定筛选条件 | 自然语言交互 |

### 4.2 核心交互

```
┌─────────────────────────────────────────────┐
│  🧠 PopSoda AI                              │
│                                             │
│  "周末想打羽毛球，在望京附近"                  │
│  ─────────────────────────────────         │
│  👤 推荐 3 个搭子：                          │
│  1. 小王 · 匹配度 92% · 望京                │
│  2. 李姐 · 匹配度 88% · 亚运村              │
│  3. 张哥 · 匹配度 85% · 来广营               │
│                                             │
│  [查看全部] [发起搭子]                       │
└─────────────────────────────────────────────┘
```

### 4.3 对话示例

**用户输入**：
> "这周末想打羽毛球，在望京附近，最好是同事圈"

**AI 响应**：
> 🎯 找到 **4** 个合适的搭子：
> | 搭子 | 匹配度 | 范围 | 位置 |
> |------|--------|------|------|
> | 小王 | 92% | 同事-字节 | 望京 SOHO |
> | 李姐 | 88% | 同事-美团 | 望京 CBD |
> | 张哥 | 85% | 同事-阿里 | 望京科技 |
> [查看详情] [发起搭子邀请]

## 五、技术架构

### 5.1 技术选型

| 层级 | 技术选型 |
|------|----------|
| 前端 | 微信小程序 |
| 后端 | Spring Boot 3.2 |
| ORM | MyBatis-Plus 3.5 |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis |
| AI | Spring AI Alibaba（百炼/DashScope） |
| LBS | 腾讯位置服务 SDK |
| IM | 腾讯云 IM |
| 文件存储 | 腾讯云 COS |
| 推送 | 腾讯推送 |

### 5.2 项目结构

```
├── wechat-mini-program/     # 微信小程序前端
│   ├── pages/
│   │   ├── home/           # AI 首页
│   │   ├── partner/        # 搭子模块
│   │   ├── activity/       # 活动模块
│   │   ├── message/        # 消息中心
│   │   └── profile/        # 个人中心
│
├── backend/                  # Spring Boot 后端
│   └── com/aipick/
│       ├── controller/
│       ├── service/

```
