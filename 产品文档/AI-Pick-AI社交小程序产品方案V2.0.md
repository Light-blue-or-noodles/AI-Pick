```
┌─────────────────────────────────────────────────────────────┐
│                      PopSoda 产品架构                        │
├─────────────────────────────────────────────────────────────┤
```

### 3.5 交互设计原则

| 原则 | 说明 |
|------|------|
| **AI 优先** | 核心操作都支持 AI 辅助，降低用户门槛 |
| **渐进式披露** | 新用户先展示核心功能，复杂功能逐步解锁 |
| **即时反馈** | 所有操作都有 Loading/成功/失败状态 |
| **匹配度可见** | 展示 AI 计算的匹配度，增加社交信任 |
| **破冰话术** | AI 自动生成打破尴尬的第一句话 |
| **手势交互** | 上滑加载更多、左右滑动切换 Tab、右滑返回 |
