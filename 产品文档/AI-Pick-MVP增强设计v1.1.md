## 一、新增功能清单

### 1.1 AI 能力集成 (新增)

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **AI 智能匹配推荐** | 基于用户兴趣、行为智能推荐搭子/活动 | P0 |
| **AI 对话助手** | 首页底部 AI 对话入口，智能解答社交问题 | P0 |
| **AI 文案生成** | 帮助用户生成搭子/活动描述文案 | P1 |
| **AI 聊天建议** | 聊天时给出回复建议 | P1 |
| **AI 个人标签** | 分析用户画像，自动生成兴趣标签 | P2 |

### 1.2 首页增强 (细化)

| 功能 | 描述 |
|------|------|
| **AI 助手入口** | 显著位置展示 AI 助手，可对话 |
| **智能搜索** | 支持自然语言搜索搭子/活动 |
| **今日运势** | 社交运势小模块，增加趣味性 |
| **附近动态** | 显示附近用户/活动的动态 |

### 1.3 搭子模块增强 (细化)

| 功能 | 描述 |
|------|------|
| **搭子筛选器** | 按距离、兴趣、类型、性别筛选 |
| **搭子匹配度** | 显示与用户的匹配百分比 |
| **搭子邀请** | 分享搭子链接邀请加入 |
| **搭子状态** | 招募中/已满/已结束 |

### 1.4 活动模块增强 (细化)

| 功能 | 描述 |
|------|------|
| **活动分类** | 按类型筛选：运动/美食/学习/娱乐 |
| **活动日历** | 月视图展示活动日程 |
| **活动提醒** | 活动开始前推送通知 |
| **活动评价** | 活动结束后可评价 |

```
         │
    ┌────┴────┐
    ▼         ▼

└───────┘ └───────┘
```

### 5.2 AI 对话能力

| 场景 | 功能 | 实现 |

| 活动推荐 | 智能匹配 | 百炼模型 + 规则 |
