# AI-Pick MVP UI/交互设计方案

> 版本：v2.0 | 日期：2026-03-05 | 状态：基于MVP产品详细设计更新

---

## 一、设计原则

### 1.1 核心原则
- **AI 优先**：首页采用对话式交互，降低用户操作成本
- **简洁高效**：减少菜单层级，突出核心功能
- **社交氛围**：通过匹配度、活跃度等指标营造活跃感

### 1.2 设计规范
- 基准网格：4rpx
- 字体：系统默认字体
- 圆角：16rpx（卡片）、24rpx（按钮）、50%（头像）
- 间距：16rpx（内边距）、24rpx（模块间距）

## 二、配色方案

### 2.1 品牌色

| 颜色 | 色值 | 用途 |
|------|------|------|
| 主色（活力橙） | `#FF6B35` | 按钮、Tab选中、高亮 |
| 辅助色（阳光黄） | `#FFB800` | 标签、徽章、渐变 |
| 成功色（薄荷绿） | `#2ED573` | 成功状态、匹配度高 |
| 警告色 | `#FF9500` | 警告提示 |
| 错误色 | `#FF3B30` | 错误提示 |
| 背景色 | `#F5F5F5` | 页面背景 |
| 卡片色 | `#FFFFFF` | 卡片背景 |
| 文字主色 | `#1A1A1A` | 标题、重要文字 |
| 文字次色 | `#666666` | 描述、辅助文字 |
| 文字淡色 | `#999999` | 占位符、禁用文字 |
| 边框色 | `#E5E5E5` | 分割线、边框 |

### 2.2 渐变方案

```
主渐变：linear-gradient(135deg, #FF6B35 0%, #FF8E53 100%)
阳光渐变：linear-gradient(135deg, #FFB800 0%, #FFD93D 100%)
AI助手渐变：linear-gradient(180deg, #667EEA 0%, #764BA2 100%)
匹配度渐变：linear-gradient(90deg, #2ED573 0%, #FF6B35 100%)
```

## 四、组件规范

### 4.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主色按钮 | 主色背景，白色文字，圆角24rpx | 主要操作 |
| 灰色按钮 | 灰色背景，黑色文字 | 次要操作 |
| 文字按钮 | 无背景，主色文字 | 辅助操作 |
| 图标按钮 | 透明背景，图标+文字 | 工具栏 |

**尺寸**：
- 大按钮：高度 96rpx，宽度 100%
- 中按钮：高度 80rpx，宽度 200rpx
- 小按钮：高度 60rpx，宽度 120rpx

### 4.2 标签

| 类型 | 样式 | 用途 |
|------|------|------|
| 选中标签 | 主色背景，白色文字 | 已选中 |
| 未选中标签 | 白色背景，边框灰色，主色文字 | 未选中 |
| 提示标签 | 黄色背景，深色文字 | 热门/警告 |
| 成功标签 | 绿色背景，白色文字 | 完成/认证 |

### 4.3 卡片

- 背景：白色
- 圆角：16rpx
- 阴影：0 4rpx 16rpx rgba(0,0,0,0.08)
- 内边距：24rpx

### 4.4 头像

| 尺寸 | 用途 |
|------|------|
| 60x60 | 列表/评论 |
| 80x80 | 个人主页 |
| 120x120 | 我的页面 |
| 200x200 | 详情页大图 |

## 五、动效规范

### 5.1 页面切换
- 动画时长：300ms
- 动画曲线：ease-in-out
- 效果：左滑进入/右滑退出

### 5.2 按钮反馈
- 点击效果：scale(0.96)
- 时长：100ms

### 5.3 加载动画
- 骨架屏：渐变闪烁
