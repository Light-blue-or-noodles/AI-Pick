## 一、产品概述

AI-Pick 是一款 AI 驱动的社交匹配小程序，通过自然语言交互和智能推荐算法，帮助用户快速找到志同道合的"搭子"（伙伴）和参与感兴趣的线上线下活动。

### 1.1 核心功能

| 模块 | 功能描述 | 状态 |

| 自然语言搜索 | AI 理解用户口语化需求，智能匹配 | ✅ 已上线 |
| 搭子系统 | 发布/应征搭子，支持多种筛选维度 | ✅ 已上线 |

| 即时通讯 | 一对一聊天，AI 辅助对话 | ✅ 已上线 |
| 社交圈子 | 同事圈、校友圈隐私社交 | ✅ 已上线 |
| 智能日历 | 活动日程管理和提醒 | ✅ 已上线 |

## 三、核心算法

### 3.1 推荐算法

**混合推荐策略**：
1. **协同过滤**：相似用户的行为推荐
2. **内容匹配**：兴趣标签匹配度计算
3. **地理位置**：基于距离的加权排序
4. **时间衰减**：新发布内容优先
5. **多样性保证**：避免结果同质化

**匹配度计算公式**：
```
匹配度 = 兴趣匹配度 × 0.4 + 地理位置分 × 0.3 + 时间新鲜度 × 0.2 + 社交关系分 × 0.1
```

### 3.2 自然语言理解

**AI 解析流程**：
1. 用户输入自然语言查询
2. 调用阿里云百炼大模型解析意图
3. 提取关键参数（地点、时间、类型）
4. 转换为结构化查询条件
5. 执行搜索并返回结果
