# 局域网真机调试

让手机和电脑在同一 WiFi 下，用真机预览/调试小程序，并访问你电脑上跑的后端。

## 1. 获取电脑局域网 IP

- **macOS**：系统设置 → 网络 → Wi‑Fi → 详情，或终端执行 `ifconfig | grep "inet "`，看 `192.168.x.x`。
- **Windows**：设置 → 网络和 Internet → WLAN → 属性，或 CMD 执行 `ipconfig`，看 IPv4 地址。

记下 IP，例如：`192.168.1.100`。

## 2. 后端允许局域网访问

本后端默认监听 `0.0.0.0:8080`，无需改配置即可被同网段设备访问。

若你改过 `server.address`，请去掉或设为 `0.0.0.0`，然后重启后端：

```bash
cd backend/aipick-backend
mvn spring-boot:run
```

确保电脑防火墙放行 8080 端口（必要时在系统防火墙里新增「入站规则」放行 TCP 8080）。

## 3. 小程序指向电脑 IP

在 **`app.js` 顶部** 修改：

```javascript
const USE_LAN = true;                    // 改为 true 开启局域网
const LAN_IP = '192.168.1.100';         // 改成你电脑的局域网 IP
```

保存后重新编译/预览，所有接口会请求 `http://192.168.1.100:8080`。

## 4. 微信开发者工具与图片显示

1. 打开项目 → 右上角 **「详情」** → **「本地设置」** 中勾选：
   - **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
2. 项目已设置 `project.config.json` 中 `setting.urlCheck: false`，便于真机预览时加载网络图片（头像、封面等）。
3. 若真机仍不显示图片：用手机浏览器直接打开接口返回的图片地址（如 `http://你的IP:8080/api/static/avatars/xxx.jpg`），能打开说明后端正常，再确认手机与电脑同一 WiFi 且未勾选「仅 WLAN」等限制。
4. 真机调试 / 预览：点击 **「真机调试」** 或 **「预览」**，用手机微信扫码即可。

## 5. 真机调试流程小结

| 步骤 | 操作 |
|------|------|
| 1 | 电脑、手机连同一 WiFi |
| 2 | 后端在电脑上运行（`mvn spring-boot:run`），防火墙放行 8080 |
| 3 | 在 `app.js` 中设 `USE_LAN = true`、`LAN_IP = '你的电脑IP'` |
| 4 | 开发者工具勾选「不校验合法域名…」 |
| 5 | 点击「预览」或「真机调试」扫码在手机上打开 |

调试结束后，把 `USE_LAN` 改回 `false`，避免提交后别人用你本地 IP。
