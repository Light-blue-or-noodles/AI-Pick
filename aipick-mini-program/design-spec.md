# AI-Pick 小程序设计规范

## 设计目标
清新风格配色，避免重配色，符合 18-35 岁年轻用户审美

## 设计原则

1. **一致性** - 统一使用设计规范的色值、间距、圆角
2. **可维护性** - 通过 CSS 变量实现快速主题切换
3. **用户体验** - 符合年轻用户审美，清新简约
4. **性能优化** - 减少不必要的阴影和渐变，保证加载速度
5. **清晰层次** - 通过颜色和大小区分信息重要性
