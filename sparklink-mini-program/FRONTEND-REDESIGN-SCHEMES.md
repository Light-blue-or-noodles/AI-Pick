# AI-Pick 小程序前端改版方案（参考七喜 mini 原型）

**当前采用：薄荷青配色 + 柔和圆角/留白，已全量落地。**

本文档基于 **frontend-designer** 角色，参考 `/Users/yanleishi/AI/七喜mini原型` 目录下的原型图风格，为 **aipick-mini-program** 提供 2～3 套前端样式与交互方案，便于评审与后续开发。**原则上不改变现有后端接口，仅做少量可接受的字段或约定补充。**

## 一、参考风格摘要（七喜 mini 原型）

| 维度 | 七喜原型特点 |
|------|--------------|
| **配色** | 白底为主，**浅绿** 为强调色（选中态、主按钮、状态标签）；黑/深灰正文，层次清晰 |
| **顶部** | 标题居中，右侧「更多」+ 头像/位置等图标 |
| **分类** | 横向滚动，带图标；选中项为 **绿色下划线 + 绿色字**，非选中灰字 |
| **筛选** | 一排四个：城市、类型、时间、费用，每项带下拉箭头，点击弹出选择器 |
| **活动列表卡片** | 圆角白卡；标题 + 发起人头像/名 + 标签；**报名中** 绿底标签；时间/距离/地点一行；**横向小图条**（多图）；「X人已上车」+ 右侧 **「报名」绿色按钮** |
| **活动详情** | 大图 Banner；标题 + 退款政策绿标签；时间/地点带图标；已报名与名额；活动描述、行程安排；**底部固定栏**：联系、分享、**我要报名(¥x)** 绿按钮 |
| **创建活动** | 分块（浅灰背景区分）；封面 + 号；标题/描述；选择类型(蓝)、活动地址(红图标)；活动时间/截止/退款/人数/价格 列表项 + 右箭头；**存草稿** 灰按钮、**发起活动** 浅绿主按钮 |
| **搭子发现** | 顶部「选择位置」+ 附近/发现 Tab（绿下划线）；卡片：类型标签、正文、搭子时间地点、头像昵称、AA/装备等标签、IP |
| **底部 Tab** | 首页、搭子、**中间大绿圆 +**、活动、我的；选中态绿色 |

整体：**简洁、留白多、信息层级清晰、主操作统一为绿色、适度圆角与阴影。**

## 二、当前问题与改进方向（对齐七喜的自然柔和）

结合你的反馈，当前存在以下可改进点，改版时建议统一按「七喜式自然柔和」处理：

| 问题 | 改进方向 |
|------|----------|
| **橙色搭配不协调** | 主色与辅助色、背景、标签的色相/明度要成体系；或直接采用下文推荐配色方案之一。 |
| **组件棱角过于明显** | 增大圆角：卡片、按钮、标签、输入框等采用**更柔和的圆角**（见下表），避免 8rpx 等偏小的值。 |
| **列表/信息页紧凑拥挤** | **加大留白与间距**：卡片内边距、列表项间距、区块间距、行高均适当放大，让信息「呼吸」。 |

### 2.1 柔和圆角规范（建议替换现有 variables）

与七喜观感一致、更自然柔和的圆角建议：

| 名称 | 当前约值 | 建议值 | 适用场景 |
|------|----------|--------|----------|
| `--radius-sm` | 8rpx | **12rpx** | 标签、小徽章 |
| `--radius-md` | 12rpx | **16rpx** | 输入框、筛选胶囊 |
| `--radius-lg` | 16rpx | **24rpx** | 卡片、列表项 |
| `--radius-xl` | 24rpx | **32rpx** | 弹窗、大卡片、底部栏 |
| `--radius-full` | 9999rpx | 9999rpx（保持） | 胶囊按钮、Tab 项 |

### 2.2 留白与间距（解决拥挤）

| 名称 | 当前约值 | 建议值 | 适用场景 |
|------|----------|--------|----------|
| 卡片内边距 | 24rpx | **28rpx～32rpx** | 活动卡片、搭子卡片内容区 |
| 列表卡片间距 | 24rpx | **28rpx～32rpx** | 列表项与项之间 |
| 区块间距 | 16～24rpx | **24rpx～32rpx** | 分类与筛选、筛选与列表之间 |
| 行高/信息行 | — | **至少 1.5 倍字号**，信息行之间 12～16rpx | 标题与副信息、多行描述 |
| 页面左右边距 | 20～28rpx | **28rpx～32rpx** | 整体内容不贴边 |

列表页建议：**单屏可见卡片数略减、单卡信息行距加大**，优先保证可读与「不挤」。

## 三、当前 AI-Pick 现状简要

- **技术栈**：微信原生小程序（WXML/WXSS），`app.json` 已配置自定义 TabBar、活动/搭子/消息/我的等页面。
- **主色**：`styles/variables.wxss` 中为 **橙色** `#FF6B35`（活力橙），与 `design-spec.md` 中的蓝色主色不一致，当前实现以 variables 为准。
- **活动页**：已有顶部搜索+日历+筛选、分类横向、时间横向、活动卡片（封面大图+状态+标题+标签+作者+进度条+整行报名按钮）、右下角 + 发布。
- **搭子页**：搜索+筛选、分类、卡片列表、发布按钮/弹窗。
- **活动详情**：轮播图、信息列表、活动详情、主办方、已报名头像、底部收藏/分享/报名。
- **后端**：活动列表、详情、报名等接口已存在；数据字段（如 title、cover、time、location、category、status、organizer、participants 等）可直接沿用。

## 四、推荐配色方案（多选一，可直观对比）

结合小程序「找活动、找搭子、轻社交」的定位与年轻用户审美，推荐以下 **5 套配色**。每套均保证主色与背景、文字、标签的协调，避免当前橙色的不协调感。确定方案后，将对应色值写入 `styles/variables.wxss` 即可。

| 方案 | 主色 | 主色浅/背景用 | 风格简述 |
|------|------|----------------|----------|
| **1 清新绿（七喜风）** | `#07C160` | `#E8F8F0` | 与七喜一致，信任、自然、易读 |
| **2 柔和蓝** | `#5B9BD5` | `#E8F4FC` | 清爽、理性，适合活动/组织感 |
| **3 暖杏** | `#D4956A` | `#FBF3EE` | 温暖不刺眼，替代当前橙更柔和 |
| **4 薄荷青** | `#5FB3A8` | `#E8F6F5` | 清新、略文艺，适合搭子/兴趣 |
| **5 淡紫** | `#9B8FDC` | `#F0EEFA` | 年轻、温和、有辨识度 |

### 方案 1：清新绿（七喜风）

- **主色**：`#07C160`（按钮、选中、Tab、主操作）
- **主色浅**：`#E8F8F0`（标签背景、选中背景、弱强调）
- **背景**：页面 `#F5F5F5`，卡片 `#FFFFFF`
- **文字**：主 `#333333`，次 `#666666`，辅 `#999999`
- **适合**：希望与七喜原型完全一致、强调「自然、靠谱」的场景。

### 方案 2：柔和蓝

- **主色**：`#5B9BD5`
- **主色浅**：`#E8F4FC`
- **背景**：页面 `#F7F9FC`，卡片 `#FFFFFF`
- **文字**：同上
- **适合**：偏「活动/组织/日程」感，清爽不花哨。

### 方案 3：暖杏（柔和版橙）

- **主色**：`#D4956A`（降低饱和度与明度，比当前橙柔和）
- **主色浅**：`#FBF3EE`
- **背景**：页面 `#FAF8F6`，卡片 `#FFFFFF`
- **文字**：同上
- **适合**：想保留「暖色、活力」但改善当前橙的刺眼与不协调。

### 方案 4：薄荷青

- **主色**：`#5FB3A8`
- **主色浅**：`#E8F6F5`
- **背景**：页面 `#F5FAF9`，卡片 `#FFFFFF`
- **文字**：同上
- **适合**：搭子、兴趣、轻社交，略带文艺感。

### 方案 5：淡紫

- **主色**：`#9B8FDC`
- **主色浅**：`#F0EEFA`
- **背景**：页面 `#F8F7FC`，卡片 `#FFFFFF`
- **文字**：同上
- **适合**：年轻、有辨识度、偏温和女性向或中性审美。

**实现**：在 `styles/variables.wxss` 中只保留一套「当前选用方案」的变量；若需多主题，再按方案 C 做两套变量与切换。

## 六、方案 A：七喜风格直接移植（清新绿）

### 6.1 设计思路

完全对齐七喜原型的「简洁清新」：白底 + 浅绿主色，分类下划线选中、一排筛选、卡片右侧报名按钮、详情底栏等，让整体观感与七喜一致。

### 6.2 配色与变量

- **主色**：`#07C160`（微信绿）或 `#52C41A`（成功绿）作为主色；浅绿 `#E8F8F0` 用于标签背景、选中背景。
- **背景**：页面 `#F5F5F5`，卡片 `#FFFFFF`。
- **文字**：主 `#333333`，次 `#666666`，辅 `#999999`。
- **TabBar**：未选 `#999999`，选中 `#07C160`；中间发布按钮为绿色圆形 + 白「+」。

在 `styles/variables.wxss` 中新增或覆盖为「七喜绿」主题变量，其它页面通过现有变量引用，**无需改后端**。

### 6.3 布局与组件

- **活动列表页**
  - 顶部：标题「活动列表」居中，右侧「⋯」+ 头像（沿用现有能力，仅样式调整）。
  - 分类：横向滚动，**仅文字 + 底部绿下划线** 选中态（可保留现有 categories 数据与接口）。
  - 筛选：**一排四个**「城市 / 类型 / 时间 / 费用」，每项右侧箭头，点击进入现有筛选页或弹窗（城市可复用七喜式双列选择器 UI，数据仍用现有接口或本地列表）。
  - 卡片：左侧为**横向小图条**（多图横向排列，无图用占位）；右侧：标题、发起人头像+名、标签、**报名中** 绿标签、时间/距离/地点一行、「X人已上车」、**右侧「报名」绿色按钮**（与七喜一致）。若当前接口仅返回单图 `cover`，可先用单图占满左侧小图区，**后端可选**：后续支持 `images[]` 多图时前端直接展示，不强制。
  - 右下角「+」：形状与位置保持不变，改为绿色圆形。

- **活动详情页**
  - 顶部：返回 + 标题/主办方头像 + 更多 + 位置图标（沿用现有逻辑，仅样式）。
  - 大图 Banner 保持。
  - 标题下增加「退款政策」标签（绿底，可先写死「默认」或从活动字段读，**后端可选** 增加 `refundPolicy` 文案）。
  - 时间/地点/人数/费用：图标 + 文字一行行排列（与七喜一致）。
  - **底部固定栏**：左侧「联系」「分享」，右侧 **「我要报名(¥x.xx)」** 绿色主按钮；收藏可并入「更多」或保留在底栏（与七喜略做取舍）。

- **搭子列表/发现**
  - 顶部「选择位置」+ 附近/发现 Tab，选中用绿下划线。
  - 卡片：类型标签（绿或灰底）、正文、搭子时间/地点、头像+昵称、AA/装备等标签、IP（若后端无 IP 可先不展示或占位，**后端可选** 一个字段）。

- **创建活动**
  - 分块（浅灰块背景）、封面 + 号、标题/描述、选择类型/地址/时间/截止/退款/人数/价格，列表项右侧箭头；底部「存草稿」灰按钮、「发起活动」绿色主按钮。与现有 `activity-create` 表单项对应，**仅样式与排版调整，接口不变**。

### 6.4 交互

- 分类、筛选、Tab 切换：**适度过渡**（如 0.2s 颜色/下划线），无复杂动效。
- 列表卡片、详情底栏：点击热区与现有逻辑一致，仅视觉改为七喜风格。
- 筛选弹窗：城市/类型/时间/费用 与现有筛选页或弹窗逻辑对接，**不新增接口**。

### 6.5 后端影响小结

- **必须**：无。
- **可选**：活动多图 `images[]`、活动 `refundPolicy` 文案、搭子 IP 展示用字段；不实现也可先占位或隐藏。

## 七、方案 B：保留橙主色 + 七喜版式与组件形态

### 7.1 设计思路

保留 AI-Pick 现有**活力橙**主色与品牌感，仅在**版式、组件形态、信息层级**上对齐七喜：更清晰的分类与筛选、卡片信息排布、详情底栏结构等，**不更换主色**。

### 7.2 配色与变量

- 继续使用 `variables.wxss` 中的 **#FF6B35** 主色、现有辅助色与背景/文字变量。
- TabBar、主按钮、选中态仍为橙色系；仅把「七喜的绿色区域」改为「橙色」即可。

### 7.3 布局与组件（与方案 A 的差异）

- **活动列表**：与方案 A 相同的**布局与组件形态**（分类下划线、一排筛选、卡片左侧小图条+右侧报名按钮），仅主色从绿改为橙。
- **活动详情**：与方案 A 相同的**区块划分与底栏**（联系、分享、我要报名），按钮与标签用橙色。
- **搭子**：同上，Tab 下划线与标签用橙色。
- **创建活动**：同 A 的分块与双按钮，主按钮为橙色。

这样可以在**零后端改动**的前提下，获得与七喜一致的**版式和交互逻辑**，仅视觉品牌保持橙色。

### 7.4 后端影响

- **无**。完全沿用现有接口与字段。

## 八、方案 C：双主题可切换（清新绿 / 活力橙）

### 6.1 设计思路

同时支持「七喜风清新绿」和「当前活力橙」两套主题，用户可在「我的」-「设置」中切换；或运营侧配置默认主题。组件结构统一，仅通过 **CSS 变量** 换肤。

### 8.2 实现要点

- **两套变量**：例如 `variables-green.wxss`（七喜绿）与 `variables-orange.wxss`（当前橙），或在单文件内用 `page[data-theme="green"]` / `page[data-theme="orange"]` 覆盖变量。
- **切换方式**：在 app 或设置页读写 `wx.setStorageSync('theme','green'|'orange')`，启动时或切换时给 `page` 设置 `data-theme`，并动态 `@import` 对应变量或切换 class。
- **组件**：与方案 A/B 相同的版式与结构，主色/辅助色全部引用变量，不写死色值。

### 8.3 后端影响

- **可选**：若希望「用户主题」跨端同步，可在用户表增加一个字段（如 `theme: 'green'|'orange'`），登录后拉取并应用；否则仅本地存储即可，**无需改接口**。

## 九、方案对比与推荐

| 维度 | 方案 A（绿） | 方案 B（橙） | 方案 C（双主题） |
|------|--------------|--------------|------------------|
| 与七喜原型一致度 | 高（含配色） | 高（仅版式） | 高（绿主题同 A） |
| 品牌延续 | 弱（换色） | 强 | 强（保留橙） |
| 后端改动 | 无必须，可选多图/退款/IP | 无 | 无必须，可选 theme |
| 实现与维护 | 一套变量 | 一套变量 | 两套变量 + 切换逻辑 |
| 适合场景 | 希望整体「换脸」为七喜风 | 希望保留品牌、只升级版式 | 希望同时满足两种审美或 A/B 测试 |

- **若目标是与七喜「看起来一致」**：选 **方案 A**。
- **若目标是在不大改品牌的前提下提升版式与体验**：选 **方案 B**。
- **若希望兼顾两种风格或后续做主题扩展**：选 **方案 C**。

## 十、后续开发建议（便于继续开发）

1. **确定方案**：在本文档中选定 A/B/C 后，可在本 MD 顶部或单独一行注明「**当前采用：方案 X**」，便于后续实现与 Code Review 对齐。
2. **实现顺序建议**
   - 先做 **全局**：`variables.wxss`（或双主题变量 + 切换）。
   - 再按页：**活动列表 → 活动详情 → 搭子列表 → 首页/我的**；最后 **创建活动**、**筛选/日历** 等。
   - 每页优先：布局与 WXML 结构 → WXSS 变量与组件形态 → 微交互（过渡、下划线切换等）。
3. **接口约定（最小化）**
   - 活动列表/详情：继续使用现有字段；若采用「卡片多图」且后端暂无 `images[]`，可先用 `cover` 单图占位。
   - 活动详情「退款政策」：无字段时展示「默认」或占位，后续可加 `refundPolicy`。
   - 搭子 IP：无则隐藏或占位。
   - 主题：仅前端存储即可，无需为方案 A/B 改后端；方案 C 若要做同步再考虑用户表字段。
4. **文档与设计规范**
   - 改版完成后可把「最终采用的配色与组件」同步回 `design-spec.md`，保持设计与实现一致。
   - 本文件可作为「产品/设计 - 前端」的对接文档，后续若增加新页面，可继续在本 MD 中追加「新页面在 X 方案下的规范」一节。

## 十一、全局实施规范一览（落地用）

以下为改版时**建议统一采用**的变量与数值，与「柔和圆角 + 加大留白」一致，可直接或稍作替换写入 `variables.wxss`。主色与主色浅从「四、推荐配色方案」中任选一套填入。

### 11.1 圆角（替换现有）

```css
--radius-full: 9999rpx;
```

### 11.2 间距（建议新增或覆盖）

```css
--spacing-xs: 12rpx;
--spacing-sm: 20rpx;
--spacing-md: 28rpx;
--spacing-lg: 36rpx;
--spacing-xl: 48rpx;
--page-horizontal: 32rpx;   /* 页面左右边距 */
--card-inner: 28rpx;        /* 卡片内边距 */
--card-gap: 28rpx;          /* 列表卡片间距 */
--block-gap: 28rpx;        /* 区块之间 */
```

### 11.3 阴影（柔和、不抢眼）

```css
--shadow-sm: 0 2rpx 12rpx rgba(0, 0, 0, 0.06);
--shadow-md: 0 4rpx 20rpx rgba(0, 0, 0, 0.08);
--shadow-lg: 0 8rpx 28rpx rgba(0, 0, 0, 0.10);
```

建议去掉或弱化当前基于蓝色的彩色阴影，统一为中性灰阴影，更自然。

### 11.4 字体与行高

```css
--font-xs: 22rpx;
--font-sm: 24rpx;
--font-base: 28rpx;
--font-lg: 32rpx;
--font-xl: 36rpx;
--font-xxl: 40rpx;
--line-tight: 1.4;
--line-normal: 1.5;
--line-relaxed: 1.6;
```

正文与多行描述建议使用 `line-height: 1.5` 及以上；信息行之间预留 12～16rpx。

## 十二、组件级规范（自然柔和）

以下组件在改版时建议统一形态，避免棱角过重、拥挤。

| 组件 | 圆角 | 内边距/高度 | 其它 |
|------|------|------------|------|
| **主按钮** | `--radius-full` | 高度 88rpx，左右 32rpx | 主色背景，白字；不加粗边框 |
| **次按钮** | `--radius-full` | 同上 | 浅灰背景 `#F5F5F5`，主文字色；或白底+主色描边 |
| **卡片** | `--radius-lg`（24rpx） | 内边距 `--card-inner`（28rpx） | 白底，阴影 `--shadow-sm` |
| **标签/徽章** | `--radius-sm`（12rpx） | 8rpx 16rpx | 主色浅背景，主色字；或灰底灰字 |
| **输入框** | `--radius-md`（16rpx） | 24rpx 28rpx，高度约 80rpx | 背景 `#F5F5F5`，focus 时主色描边 2rpx |
| **底部固定栏** | 顶部 `--radius-xl`（32rpx） | 栏高 100rpx + 安全区 | 白底，上阴影；主按钮用主色 |
| **分类 Tab** | 无圆角或仅底部圆角 | 项间距 32rpx，padding 12rpx 0 | 选中：主色 + 底部 4rpx 条；未选：灰字 |
| **筛选条** | 每项 `--radius-md` | 高度 64rpx，项间距 16rpx | 灰底或白底，右箭头；点击弹出选择器 |
| **列表项** | `--radius-lg` | 同上卡片 | 与卡片一致，项与项之间 `--card-gap` |

所有可点击区域建议最小高度 88rpx 或最小点击区域 44pt，符合触屏与无障碍习惯。

## 十三、分页布局要点（解决拥挤）

各页在改版时建议遵循以下区块与间距，保证「呼吸感」。

### 13.1 活动列表页

- **顶部栏**：高度约 88rpx + 安全区；标题居中，右侧图标；与下方区块间距 `--block-gap`。
- **分类**：单行横向滚动；与筛选条间距 16～20rpx；分类项之间 24rpx。
- **筛选条**：城市/类型/时间/费用 一排；与列表间距 `--block-gap`。
- **列表**：左右边距 `--page-horizontal`；卡片间距 `--card-gap`；单卡内容区使用 `--card-inner`，标题与副信息、副信息行之间至少 12rpx。
- **右下角发布按钮**：与 TabBar 留出间距，不遮挡最后一张卡片。

### 13.2 活动详情页

- **Banner 图**：保持全宽；与下方信息区块间距 24rpx。
- **信息区块**：标题与时间/地点/人数等行距 16rpx；区块内 padding 28rpx；区块与区块之间 24～32rpx。
- **详情/主办方/已报名**：每块有明确 section 标题，标题与内容 12rpx；正文行高 1.5。
- **底部固定栏**：与内容区留出足够 padding-bottom，避免被安全区遮挡。

### 13.3 搭子列表页

- **顶部**：「选择位置」+ 附近/发现 Tab；与列表间距 `--block-gap`。
- **卡片**：圆角、内边距、标签形态与活动卡统一规范；卡片间距 `--card-gap`；单卡内类型标签与正文、正文与时间地点、时间地点与用户信息 分层留白（12～16rpx）。

### 13.4 创建活动页

- **分块**：每块浅灰背景 `#F5F5F5`，块与块之间 16～20rpx；块内 padding 28rpx。
- **表单项**：label 与 input 间距 12rpx；项与项之间 24rpx；右侧箭头与文字间距 12rpx。
- **底部双按钮**：并排时中间 20rpx；与内容区 32rpx；按钮高度与主按钮一致。

### 13.5 首页、我的

- **首页**：欢迎区、AI 入口、快捷入口、附近动态、推荐搭子 各区块之间 `--block-gap`；卡片与列表项同样采用加大内边距与圆角。
- **我的**：列表项高度不小于 96rpx，左侧图标与文字、文字与箭头 留足间距；分组之间 16～20rpx。

## 十四、与现有文件的对应关系

改版时建议按以下顺序与文件修改，便于排查与回滚：

| 目标 | 主要涉及文件 |
|------|--------------|
| 全局变量（配色、圆角、间距、阴影） | `styles/variables.wxss` |
| 通用组件样式（按钮、卡片、标签、输入框） | `styles/common.wxss` |
| 活动列表/详情/创建 | `pages/activity/*`、`pages/activity-detail/*`、`pages/activity-create/*`，及 `styles/circle.wxss`（若仍引用） |
| 搭子列表/发布 | `pages/partner/*`、`pages/partner-publish/*`，及 `styles/match.wxss` |
| 首页 | `pages/index/*`、`styles/home.wxss` |
| 我的/设置 | `pages/profile/*`、`pages/settings/*`、`styles/profile.wxss` |
| 底部 Tab | `custom-tab-bar/*`、`app.json`（仅 tabBar 颜色等） |
| 筛选/日历 | `pages/filter/*`、`pages/calendar/*` |

优先改 `variables.wxss`，再在各页中逐步替换圆角、间距、主色引用；最后统一微调阴影与字体行高。
