## 四、开发调试

### 4.1 本地开发调试

```bash
# 确保后端服务已启动
# 本地：http://localhost:8080/api
# 或连接服务器：http://59.110.0.107:8080/api
```

**调试技巧：**

1. **真机调试**：
   - 点击「真机调试」→ 扫码
   - 手机上的操作会同步到开发者工具控制台

2. **预览**：
   - 点击「预览」→ 扫码
   - 快速查看效果，不生成体验版

3. **远程调试**：
   - 打开「调试器」面板
   - 查看 Network、Console、Storage

### 4.2 常见调试问题

| 问题 | 解决方案 |
|------|---------|
| `request:fail` | 检查「不校验合法域名」是否勾选 |
| 接口返回 404 | 检查 apiBaseUrl 配置 |
| 登录失败 | 确认后端服务正常运行 |
| 图片不显示 | 检查图片域名是否在白名单中 |

## 五、上传代码

### 5.1 代码审查

上传前检查清单：

- [ ] `app.js` 中的 `apiBaseUrl` 指向正确环境
- [ ] 没有硬编码的测试数据
- [ ] 没有 `console.log` 调试代码（或已注释）
- [ ] 图片资源已压缩
- [ ] 代码包大小 < 2MB（单个分包）

### 5.2 上传步骤

1. 点击「上传」按钮
2. 填写版本号（如：`v1.0.0`）
3. 填写项目备注（更新内容）
4. 点击「上传」

**版本号规范：**

```
主版本号.次版本号.修订号

示例：
v1.0.0 - 初始版本
v1.1.0 - 新增功能
v1.1.1 - Bug 修复
v2.0.0 - 重大更新
```

## 六、提交审核

### 6.1 微信公众平台操作

1. 登录[微信公众平台](https://mp.weixin.qq.com/)
2. 进入「管理」→「版本管理」
3. 找到「开发版本」，点击「提交审核」

### 6.2 填写审核信息

**基本信息：**

| 字段 | 填写内容 |
|------|---------|
| 版本号 | 自动填充 |
| 更新说明 | 本次更新的功能点 |
| 测试账号 | 提供测试账号（如有登录功能） |
| 测试密码 | 测试账号密码 |

**审核补充说明：**

```
示例：
1. 本项目为 AI 社交匹配小程序
2. 测试账号：test_user / 123456
3. 主要功能：用户注册、搭子发布、智能匹配、即时通讯
4. 如需完整体验，请使用测试账号登录
```

### 6.3 所需材料

根据小程序类目准备：

| 类目 | 所需材料 |
|------|---------|
| 社交 | ICP 备案、增值电信业务经营许可证（部分情况） |
| 工具 | 一般无需额外材料 |
| 生活服务 | 营业执照、相关资质 |

## 七、发布上线

### 7.1 审核通过

审核通常需要 **1-3 个工作日**。

审核状态查看：
- 微信公众平台 → 版本管理
- 或接收微信通知

### 7.2 正式发布

审核通过后：

1. 进入「版本管理」
2. 找到「审核版本」
3. 点击「发布」
4. 确认发布

**发布后：**
- 全量发布：所有用户可见
- 灰度发布：部分用户可见（可选）

## 八、域名配置（生产环境）

### 8.1 配置业务域名

1. 微信公众平台 → 开发 → 开发管理 → 开发设置
2. 找到「服务器域名」
3. 点击「修改」

**request 合法域名：**
```
https://your-domain.com
```

**uploadFile 合法域名：**
```
https://your-domain.com
```

**downloadFile 合法域名：**
```
https://your-domain.com
https://your-cdn-domain.com
```

### 8.2 配置业务域名（webview）

如需使用 web-view 组件：

```
https://your-h5-domain.com
```

### 8.3 HTTPS 证书

- 必须使用 HTTPS
- 证书需有效且未过期
- 不支持自签名证书

## 九、更新迭代

### 9.1 日常更新流程

```
开发 → 测试 → 上传 → 提交审核 → 发布
```

### 9.2 热更新 vs 版本更新

| 方式 | 适用场景 | 用户感知 |
|------|---------|---------|
| 热更新（数据） | 配置、文案修改 | 无 |
| 版本更新（代码） | 功能新增、Bug 修复 | 需重新打开小程序 |

### 9.3 版本回退

如线上版本出现问题：

1. 微信公众平台 → 版本管理
2. 找到历史版本
3. 点击「回退」
4. 确认回退

## 十一、常见问题

### 11.1 审核被拒常见原因

| 原因 | 解决方案 |
|------|---------|
| 类目不符 | 调整类目或补充资质 |
| 功能不完整 | 完善功能后再提交 |
| 内容违规 | 删除违规内容 |
| 用户体验差 | 优化交互和界面 |

### 11.2 性能优化建议

1. **图片优化**
   - 使用 WebP 格式
   - 懒加载长列表图片
   - 压缩图片大小

2. **代码优化**
   - 分包加载
   - 按需引入组件
   - 避免重复 setData

3. **网络优化**
   - 接口缓存
   - 合并请求
   - 使用 CDN
