## 一、阿里云域名申请

### 1.1 域名注册流程

1. **访问阿里云域名服务**
   - 网址：https://domain.aliyun.com/
   - 或直接访问：https://www.aliyun.com/product/domain

2. **查询域名**
   - 在搜索框输入想要注册的域名（如 aipick.ai、aipick.com 等）
   - 查看域名是否可注册及价格

3. **加入购物车并结算**
   - 选择需要的域名后缀
   - 添加到购物车
   - 完成实名认证（个人用户需上传身份证）

4. **支付完成**
   - 支持支付宝、微信、银行卡等支付方式
   - 支付成功后域名即刻生效

### 1.2 域名费用

| 域名后缀 | 首年价格（参考） | 续费价格 |
|---------|----------------|---------|
| .com    | 60-80元        | 80-100元 |
| .cn     | 30-50元        | 50-70元  |
| .ai     | 100-150元      | 150-200元 |
| .app    | 60-80元        | 80-100元 |

### 1.3 域名实名认证

- 个人注册：需上传身份证正反面
- 企业注册：需上传营业执照
- 认证时间：通常1-3个工作日

## 二、域名与阿里云服务器绑定

### 2.1 前提条件

- 已有阿里云服务器（ECS、轻量应用服务器等）
- 已完成域名注册和实名认证

### 2.2 解析配置步骤

1. **进入阿里云DNS控制台**
   - 访问：https://dns.console.aliyun.com/
   - 登录阿里云账号

2. **添加域名**
   - 点击"添加域名"
   - 输入已注册的域名

3. **添加解析记录**
   
   **方式一：通过IP地址解析（推荐用于测试/开发）**
   
   | 记录类型 | 主机记录 | 记录值（服务器公网IP） |
   |---------|---------|----------------------|
   | A       | @       | 你的服务器公网IP      |
   | A       | www     | 你的服务器公网IP      |
   
   **方式二：通过CNAME解析（推荐用于生产环境）**
   
   | 记录类型 | 主机记录 | 记录值                    |
   |---------|---------|-------------------------|
   | CNAME   | @       | 你的域名解析商提供的地址  |
   | CNAME   | www     | 你的域名解析商提供的地址  |

4. **验证解析**
   - 使用命令：`ping yourdomain.com`
   - 如果返回服务器IP，说明解析成功

### 2.3 你的服务器信息（根据MEMORY整理）

```
服务器IP：需查询你的阿里云ECS控制台
端口：8080（后端服务）
上下文路径：/api
```

**配置示例**：
- 域名：`aipick.com`
- 访问地址：`https://aipick.com/api/...`
- 备案完成后可配置HTTPS

## 三、微信小程序域名备案

### 3.1 备案要求

根据微信官方文档：
- 业务域名只支持HTTPS协议
- 域名需经过ICP备案
- 新备案域名需**24小时后才可配置**
- 不支持IP地址

### 3.2 ICP备案流程（阿里云）

#### 步骤1：准备备案材料

| 类型 | 所需材料 |
|-----|---------|
| 个人 | 身份证正反面、手持身份证照片、网站负责人照片 |
| 企业 | 营业执照、法人身份证、网站负责人身份证 |

#### 步骤2：在阿里云提交备案

1. 访问：https://beian.aliyun.com/
2. 点击"开始备案"
3. 填写主办单位信息（个人/企业）
4. 填写网站信息：
   - 网站名称
   - 网站域名
   - 服务器地域（选择阿里云）
   - 网站用途（选择"小程序"）
5. 上传备案资料
6. 完成真实性核验（人脸识别或阿里云APP扫码）

#### 步骤3：阿里云初审（1-2个工作日）

- 阿里云审核专员会电话核实信息
- 如有问题会通过短信/邮件通知修改

#### 步骤4：工信部短信核验

- 收到核验短信后，24小时内完成核验
- 短信核验链接：https://beian.miit.gov.cn/

#### 步骤5：管局审核（5-20个工作日）

- 各省管局审核时间不同
- 审核通过后收到备案号

#### 步骤6：备案成功后操作

1. 在阿里云控制台获取备案号
2. 在小程序后台添加业务域名
3. 在网站底部添加备案号和链接

### 3.3 小程序后台配置

1. 登录小程序后台：https://mp.weixin.qq.com/
2. 进入"开发管理" → "开发设置" → "业务域名"
3. 点击"新增"
4. 输入已备案的域名（格式：https://aipick.com）
5. 下载验证文件并上传到服务器根目录
6. 验证通过后保存

## 五、关键注意事项

1. **备案前提**：必须使用阿里云中国内地服务器才能在阿里云备案
2. **香港/海外服务器**：无需备案，但小程序业务域名要求ICP备案
3. **备案有效期**：备案成功后需每年进行例行检查
4. **公安联网备案**：网站开通后30天内还需完成公安备案
5. **小程序业务域名**：
   - 必须是已备案域名
   - 只支持HTTPS
   - 新备案需24小时后才能配置

## 六、常见问题

### Q1：域名已备案但小程序配置失败？
- 确认是否已满24小时
- 检查是否使用HTTPS
- 确认验证文件是否正确放置

### Q2：备案被驳回常见原因？
- 网站名称不符合规范
- 资料照片不清晰
- 网站内容与备案信息不符

### Q3：没有阿里云服务器怎么办？
- 需先购买阿里云ECS或轻量应用服务器
- 服务器地域选择中国内地（华北、华东等）
