# AI-Pick 前端开发规范

> 基于 Airbnb JavaScript Style Guide 和微信小程序最佳实践

## 1. 代码风格

### 1.1 缩进与空格
- 使用 **2 空格**缩进（微信小程序默认）
- 行尾不保留多余空格
- 文件末尾保留一个空行
- 大括号风格：Braces style: 1TBS (同一行开)

```javascript
// ✅ 正确
if (condition) {
  doSomething();
} else {
  doSomethingElse();
}

// ❌ 错误
if (condition)
{
  doSomething();
}
```

### 1.2 分号
- 必须使用分号
- 不依赖 ASI (自动分号插入)

```javascript
// ✅ 正确
const name = 'AI-Pick';
doSomething();

// ❌ 错误
const name = 'AI-Pick'
doSomething()
```

### 1.3 引号
- 字符串使用单引号 `''`
- JSON 字段使用双引号 `""`

```javascript
// ✅ 正确
const name = 'AI-Pick';
const json = { "type": "activity" };

// ❌ 错误
const name = "AI-Pick";
```

## 2. 命名规范

### 2.1 文件命名
| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 页面 | kebab-case | `activity-detail.js` |
| 组件 | PascalCase | `UserCard.vue` / `UserCard` |
| 工具函数 | kebab-case | `format-date.js` |
| 常量 | UPPER_SNAKE_CASE | `API_URL.js` |
| 图片资源 | kebab-case | `icon-plus.png` |

### 2.2 变量命名
| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 变量 | camelCase | `userInfo`, `activityList` |
| 函数 | camelCase (动词前缀) | `getUserInfo()`, `fetchActivityList()` |
| 类/组件 | PascalCase | `class UserService {}` |
| 布尔变量 | is/has/can 前缀 | `isLoading`, `hasError`, `canEdit` |
| 组件 Props | camelCase | `userId`, `activityTitle` |

### 2.3 微信小程序特有命名
```javascript
// 页面 JS 文件 - 与 page 目录名对应
// pages/user-profile/user-profile.js

// Page 命名
Page({
  data: { ... },
  onLoad(options) { ... }
});

// 自定义组件
Component({
  properties: { ... },
  data: { ... },
  methods: { ... }
});
```

## 5. 请求封装

### 5.1 request.js 封装
```javascript
const BASE_URL = 'https://api.aipick.example.com';

const request = (options) => {
  return new Promise((resolve, reject) => {
    const token = wx.getStorageSync('token');
    
    wx.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data || {},
      header: {
        'Content-Type': 'application/json',
        'Authorization': token ? `Bearer ${token}` : '',
        ...options.header
      },
      success: (res) => {
        if (res.data.code === 0) {
          resolve(res.data.data);
        } else {
          wx.showToast({
            title: res.data.message || '请求失败',
            icon: 'none'
          });
          reject(res.data);
        }
      },
      fail: reject
    });
  });
};

export default request;
```

## 7. 页面生命周期

### 7.1 页面加载顺序
```javascript
Page({
  // 1. 页面加载
  onLoad(options) {
    // options 包含路由参数
    this.setData({ id: options.id });
    this.fetchData();
  },

  // 2. 页面显示
  onShow() {
    // 每次进入页面都执行
    this.refreshData();
  },

  // 3. 页面渲染完成
  onReady() {
    // 首次渲染完成后执行
  },

  // 4. 页面隐藏
  onHide() {
    // 页面进入后台时执行
  },

  // 5. 页面卸载
  onUnload() {
    // 页面销毁时执行，清除定时器等
  },

  // 下拉刷新
  onPullDownRefresh() {
```

## 8. 数据管理

### 8.1 setData 使用规范
```javascript
// ✅ 正确 - 只更新必要的字段
this.setData({
  'userInfo.name': newName,
  loading: false
});

// ❌ 错误 - 避免频繁全量更新
this.setData({
  allData: newAllData  // 性能问题
});

// ✅ 正确 - 使用箭头函数更新数组
this.setData({
  'list[0].name': 'New Name'
});

// ✅ 正确 - 拼接路径更新
const index = this.data.list.findIndex(item => item.id === id);
this.setData({
  [`list[${index}].status`]: 'done'
});
```

### 8.2 本地存储

```javascript
const token = wx.getStorageSync('token');
```

## 9. 错误处理

### 9.1 请求错误
```javascript
const fetchData = async () => {
  try {
    this.setData({ loading: true });
    const data = await request({ url: '/api/data' });
    this.setData({ data, error: null });
  } catch (error) {
    this.setData({ 
      error: error.message || '网络错误' 
    });
    console.error('Fetch error:', error);
  } finally {
    this.setData({ loading: false });
  }
};
```

### 9.2 表单验证
```javascript
const validateForm = () => {
  const { name, phone } = this.data;
  
  if (!name || name.trim() === '') {
    wx.showToast({ title: '请输入姓名', icon: 'none' });
    return false;
  }
  
  if (!/^1\d{10}$/.test(phone)) {
    wx.showToast({ title: '手机号格式错误', icon: 'none' });
    return false;
  }
  
  return true;
};
```
