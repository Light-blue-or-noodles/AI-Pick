## 技术实现

```
用户输入 → AI 意图识别 → 参数提取 → 检索匹配 → 个性化排序 → 返回结果
   ↓
自然语言 → NLU/意图   → 实体    → ES/MySQL  → LLM 重排    → 生成回复
```

### 意图识别
- 识别用户意图：找搭子 / 找活动 / 找圈子
- 提取实体：时间、地点、兴趣、圈子范围

### 检索匹配
- 根据提取的实体从数据库检索
- 结合用户画像和历史行为

### LLM 重排
- 使用大模型对结果进行个性化排序
- 生成友好的回复文案

## 颠覆性特点

1. **无菜单导航** - 一切通过对话完成
2. **懂你所需** - AI 记住你的偏好，学习你的习惯
3. **主动推荐** - 不是等用户搜索，而是 AI 主动推荐
4. **零门槛** - 不用学筛选器，说话就行
5. **个性化** - 每个人看到的内容不同，因人而异
