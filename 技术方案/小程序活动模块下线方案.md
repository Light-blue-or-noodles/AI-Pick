# 小程序活动模块下线方案

> 版本：v1.0  
> 日期：2026-03-29  
> 范围：`aipick-mini-program`（微信小程序）  
> 目标：精简 MVP，聚焦搭子与关注链路；活动相关页面、入口、接口调用与产品文案一并收敛。

## 1. 原则

- **代码以直接删除为主**，历史依赖 Git 回溯；避免大段注释残留为技术债。
- 后端 `/api/activity/**` 可阶段性保留，前端不再调用；后端收敛按需排期。
- 搭子帖中的 **「活动时间」**（计划时间展示）属于搭子字段，**不属于本方案中的「活动模块」**，可保留。

---

## 2. 整页删除（连目录删除）

| 路径 | 说明 |
|------|------|
| `pages/activity/` | 活动 Tab 主列表、跳转筛选 |
| `pages/activity-detail/` | 活动详情、收藏、报名 |
| `pages/activity-create/` | 发布活动 |
| `pages/my-activity/` | 我的活动 |
| `pages/calendar/` | 活动日历（`/api/activity/calendar`） |

删除后从 **`app.json` 的 `pages` 数组**中移除上述路径（含 `pages/calendar/calendar`）。

---

## 3. `app.json` 调整

- **`pages`**：去掉活动相关页与日历页条目。
- **`tabBar.list`**：删除「活动」项（`pagePath: pages/activity/activity` 及图标）。
- **`permission`**（可选）：`scope.userLocation` / `scope.album` / `scope.camera` 文案中与「活动」强绑定的描述改为仅搭子或与实际上线能力一致，避免审核文案不一致。

---

| `custom-tab-bar/index.wxss` | 按需删除活动图标相关样式/注释 |

## 5. 保留页面内的修改清单

### 5.1 首页 `pages/index/`

**`index.js`**

- `loadNearbyDynamics()`：当前请求 `${baseUrl}/api/activity`，需改为搭子/首页动态等接口，或移除「附近动态」区块。
- `goToActivity`：删除或去除所有调用。
- `goToCalendar`：日历页删除后，删除入口与函数。
- `goToNearby`：当前 `switchTab` 至活动页，需改为搭子 Tab 或其它列表。
- `goToDetail`：删除 `type === 'activity'` 分支；数据映射不再使用 `type: 'activity'`。

**`index.wxml`**

- 「活动日历」入口删除或改为与产品一致的非活动能力。
- 注释块「找活动」可彻底删除。
- 文案「活动标签」若实际为搭子标签，改为「搭子标签」等。
- `defaultSrc="/images/empty-activity.png"` 可替换为搭子占位图（若仍用于动态配图）。

**`index.wxss`**

- `.home-activity-*`、仅服务已下线入口的样式可删。

### 5.2 个人中心 `pages/profile/profile.js`

- 删除菜单项 **我的活动**（跳转 `my-activity`）。
- **我的收藏**：当前 `my-favorites` 仅对接活动收藏；下线活动后删除入口并删除或重写页面（见 5.3）。

### 5.3 我的收藏 `pages/my-favorites/`

- 全页依赖 **`/api/activity/favorites`** 与 **`activity-detail`**。
- **建议**：整页从 `app.json` 删除，`profile` 去掉入口；若未来做「搭子收藏」需新接口与 UI，单独立项。

### 5.4 筛选 `pages/filter/`

- **`filter.wxml`**：删除所有 `wx:if="{{pageType === 'activity'}}"` 区块。
- **`filter.js`**：收敛 `pageType === 'activity'`、`activityType` / `activityStatus` 及仅活动使用的 `timeRange` 逻辑；禁止 `filter?type=activity` 入口。

### 5.5 AI 助手 `pages/ai-chat/`

- **`ai-chat.js`**：删除 `activity` 类型跳转 `activity-detail`；默认图 `activity-banner` 改为统一占位。
- **`ai-chat.wxml`**：副标题、快捷问题（如「运动活动」「附近有什么活动」）、placeholder 中与活动相关的文案改为仅搭子或产品定型文案。

### 5.6 聊天 `pages/chat/`

- **`chat.js`**：欢迎语与自动回复中「推荐活动」类表述调整。
- **`chat.wxml`**：快捷回复「推荐一些活动」删除或改写。

### 5.7 设置与隐私

- **`pages/settings/`**：删除 `activityNotification` 及「活动提醒」UI（若不做活动推送）。
- **`pages/privacy-settings/`**：删除「谁可以看我的活动」及 `activityVisibility*` 字段同步逻辑；后端若有对应设置需一并评估。

### 5.8 关于我们 `pages/about-us/about-us.wxml`

- 「多元活动」等特性描述改为与「只做搭子」一致。

### 5.9 发布搭子 `pages/partner-publish/`

- **`partner-publish.js`**：图片上传 URL 现为 **`/api/activity/upload-image`**，需与后端确认是否改为 **`/api/partner/...`** 或通用上传接口，避免活动路径名残留。

### 5.10 我的关注 `pages/my-following/`

- **`my-following.wxml`**：`活动 {{item.activitiesCount}}` 删除或改为后端仍返回时的展示策略（仅搭子统计等）。

## 8. 后端接口（前端清零目标）

以下调用在实施完成后应不再出现，或已被替换：

- `GET/POST` 等：`/api/activity`、 `/api/activity/:id`
- 收藏/报名：`/api/activity/**/favorite**`、`/api/activity/**/join`、`/api/activity/**/cancel`
- `GET /api/activity/calendar`
- `POST /api/activity/ai/description`、`POST /api/activity`、上传 `/api/activity/upload-image`
- `GET /api/activity/favorites`

后端表与 Controller 是否物理删除另立任务；本方案以前端与产品口径收敛为主。

---

## 9. 建议实施顺序

1. 修改 **`app.json` + custom-tab-bar + 各 Tab 页 `selected`**，保证 Tab 与下标正确。  
2. 删除活动相关页面目录与日历页，清理所有指向这些页的导航。  
3. 改造首页「附近动态」数据源与 **`goToNearby`**。  
4. 处理 **`my-favorites` / 我的收藏** 与 **profile** 入口。  
5. 全局 `grep`：`activity`、`activity-detail`、`/api/activity`、`活动` 做收尾与文案统一。
