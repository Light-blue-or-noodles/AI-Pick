# AI-Pick 后端开发规范

> 基于《Java 开发手册（嵩山版）》，结合本项目特点补充

## 1. 命名规范

### 1.1 包命名
- 全部小写
- 单词用 `.` 分隔
- 模块包：`com.aipick.模块名`

```java
// ✅ 正确
package com.aipick.user;
package com.aipick.activity.controller;

// ❌ 错误
package com.aipick.User;
package com.aipick.userController;
```

### 1.2 类命名
- 使用 **UpperCamelCase**（大驼峰）
- 常见类后缀：`Controller`, `Service`, `ServiceImpl`, `Mapper`, `Entity`, `DTO`, `VO`, `Request`, `Response`

```java
// ✅ 正确
public class UserController {}
public class UserService {}
public class UserServiceImpl {}
public class ActivityMapper {}

// ❌ 错误
public class userController {}
public class user_service {}
```

### 1.3 方法命名
- 使用 **lowerCamelCase**（小驼峰）
- 动词前缀：`get`, `set`, `save`, `delete`, `update`, `list`, `page`, `count`, `fetch`

```java
// ✅ 正确
public User getUserById(Long id);
public PageResult<UserVO> listUsers(UserQuery query);
public void saveActivity(Activity activity);
public boolean updateUserStatus(Long userId, Integer status);

// CRUD
saveXxx()    // 新增
removeById() // 删除
updateXxx() // 修改
getById()   // 查询单个
listXxx()   // 查询列表
pageXxx()   // 分页查询
```

### 1.4 变量命名
- 临时变量：`i`, `j`, `k`, `err`, `ctx`
- 循环变量：`user`, `item`, `activity`（单数）
- 集合变量：`userList`, `activityList`（复数加 List）
- 布尔变量：`isValid`, `hasError`, `canEdit`, `needRefresh`

```java
// ✅ 正确
List<User> userList = new ArrayList<>();
Map<String, Object> params = new HashMap<>();
boolean isLoading = false;
boolean hasPermission = true;

// ❌ 错误
List<User> users = new ArrayList<>();  // 不推荐
boolean flag = true;
```

### 1.5 常量命名
- 使用 **UPPER_SNAKE_CASE**
- 按功能分类存放

```java
// ✅ 正确
public class UserStatus {
    public static final int NORMAL = 1;
    public static final int DISABLED = 0;
}

public class ActivityType {
    public static final String ONLINE = "ONLINE";
    public static final String OFFLINE = "OFFLINE";
}
```

## 2. 代码格式

### 2.1 缩进与空格
- 使用 **4 空格**缩进
- 行长不超过 **120 字符**
- 运算符前后加空格

```java
// ✅ 正确
public User getUserById(Long id) {
    if (id == null || id <= 0) {
        throw new BusinessException("ID无效");
    }
    return userMapper.selectById(id);
}

// ❌ 错误
public User getUserById(Long id){
    if(id==null||id<=0){
        throw new BusinessException("ID无效");
    }
    return userMapper.selectById(id);
}
```

### 2.2 大括号
- 使用 **1TBS**（同一行开）

```java
// ✅ 正确
if (condition) {
    doSomething();
} else {
    doSomethingElse();
}

// ❌ 错误
if (condition)
{
    doSomething();
}
```

### 2.3 类结构顺序
1. 常量
2. 成员变量
3. 构造方法
4. 公共方法
5. 私有方法

```java
public class UserController {
    
    // 1. 常量
    private static final Logger log = LoggerFactory.getLogger(UserController.class);
    
    // 2. 成员变量
    private final UserService userService;
    
    // 3. 构造方法
    public UserController(UserService userService) {
        this.userService = userService;
    }
    
    // 4. 公共方法
    @GetMapping("/{id}")
    public Result<UserVO> getById(@PathVariable Long id) {
        return Result.success(userService.getUserById(id));
    }
    
    // 5. 私有方法
    private void validateUser(User user) {
        // ...
    }
}
```

## 3. Controller 层规范

### 3.1 URL 命名
- 资源名用复数：`/users`, `/activities`
- 嵌套资源：`/users/{userId}/activities`
- 使用标准 HTTP 方法

| 方法 | 用途 | 示例 |
|------|------|------|
| GET | 查询 | GET /users/{id} |
| POST | 创建 | POST /users |
| PUT | 完整更新 | PUT /users/{id} |
| PATCH | 部分更新 | PATCH /users/{id}/status |
| DELETE | 删除 | DELETE /users/{id} |

### 3.2 返回结果
```java
// ✅ 正确
@RestController
@RequestMapping("/users")
public class UserController {
    
    @GetMapping("/{id}")
    public Result<UserVO> getById(@PathVariable Long id) {
        UserVO user = userService.getUserById(id);
        return Result.success(user);
    }
    
    @PostMapping
    public Result<Long> create(@RequestBody @Valid CreateUserRequest request) {
        Long id = userService.createUser(request);
        return Result.success(id);
    }
    
    @GetMapping("/page")
    public Result<PageResult<UserVO>> page(@Valid UserPageQuery query) {
        PageResult<UserVO> result = userService.page(query);
        return Result.success(result);
    }
}
```

### 3.3 异常处理
```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.error(e.getMessage());
    }
    
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldError().getDefaultMessage();
        return Result.error(message);
    }
    
    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.error("系统错误");
    }
}
```

## 4. Service 层规范

### 4.1 事务控制
```java
@Service
public class UserService {
    
    @Transactional(rollbackFor = Exception.class)
    public Long createUser(CreateUserRequest request) {
        // 1. 验证
        validateRequest(request);
        
        // 2. 转换
        User user = convertToEntity(request);
        
        // 3. 业务逻辑
        checkDuplicate(request.getPhone());
        
        // 4. 保存
        userMapper.insert(user);
        
        // 5. 返回
        return user.getId();
    }
}
```

## 5. Mapper 层规范

### 5.1 方法命名（MyBatis-Plus）
```java
public interface UserMapper extends BaseMapper<User> {
    
    // 条件查询
    List<User> selectByPhone(String phone);
    
    // 自定义 SQL
    List<User> selectByCondition(@Param("query") UserQuery query);
    
    // 联表查询
    @Select("SELECT u.*, r.role_name FROM user u LEFT JOIN role r ON u.role_id = r.id WHERE u.id = #{id}")
    UserVO selectUserWithRole(@Param("id") Long id);
}
```

### 5.2 XML 文件结构
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.aipick.user.mapper.UserMapper">
    
    <resultMap id="BaseResultMap" type="com.aipick.user.entity.User">
        <id column="id" property="id"/>
        <result column="name" property="name"/>
        <result column="phone" property="phone"/>
        <result column="create_time" property="createTime"/>
    </resultMap>
    
    <select id="selectByCondition" resultMap="BaseResultMap">
        SELECT * FROM user
        <where>
            <if test="query.name != null and query.name != ''">
                AND name LIKE CONCAT('%', #{query.name}, '%')
            </if>
            <if test="query.status != null">
                AND status = #{query.status}
            </if>
        </where>
        ORDER BY create_time DESC
    </select>
</mapper>
```

## 6. VO/DTO/Entity 规范

### 6.1 各层对象命名
| 对象 | 用途 | 位置 |
|------|------|------|
| Entity | 数据库实体 | service/ entity |
| DTO | 数据传输对象 | controller → service |
| VO | 视图返回对象 | service → controller |
| Request | 请求参数 | controller |
| Response | 响应参数 | controller |

### 6.2 Entity 示例
```java
@Data
@EqualsAndHashCode(callSuper = true)
@TableName("user")
public class User extends BaseEntity {
    
    private String name;
    private String phone;
    private String avatar;
    private Integer status;
    private Long createBy;
    private LocalDateTime createTime;
}
```

### 6.3 VO 示例
```java
@Data
@Builder
public class UserVO {
    
    private Long id;
    private String name;
    private String phone;
    private String avatar;
    private Integer status;
    private String statusText;
    private LocalDateTime createTime;
    
    // 扩展字段
    private Integer activityCount;
    private List<String> tags;
}
```

## 7. 日志规范

### 7.1 日志级别使用
```java
// DEBUG: 调试信息，生产环境关闭
log.debug("查询参数: {}", JSON.toJSONString(params));

// INFO: 业务关键节点
log.info("用户登录成功, userId: {}, phone: {}", userId, phone);

// WARN: 业务异常，但可继续
log.warn("验证码已失效, phone: {}", phone);

// ERROR: 系统错误，需要处理
log.error("发送短信失败", e);
```

### 7.2 日志内容规范
```java
// ✅ 正确 - 包含关键上下文
log.info("创建活动成功, activityId: {}, userId: {}", activity.getId(), userId);

// ❌ 错误 - 信息不足
log.info("创建成功");

// ✅ 正确 - 异常日志记录完整堆栈
try {
    // 业务逻辑
} catch (Exception e) {
    log.error("处理用户请求失败, userId: {}, params: {}", userId, params, e);
}
```

## 8. 异常处理规范

### 8.1 业务异常
```java
// 定义异常
public class BusinessException extends RuntimeException {
    public BusinessException(String message) {
        super(message);
    }
}

// 抛出异常
if (user == null) {
    throw new BusinessException("用户不存在");
}

// 或者使用 Result
if (user == null) {
    return Result.error("用户不存在");
}
```

### 8.2 参数校验
```java
// 使用 @Validated
@PostMapping
public Result<Void> create(@RequestBody @Valid CreateUserRequest request) {
    // Controller 自动校验
    return Result.success();
}

// Request 对象
@Data
public class CreateUserRequest {
    
    @NotBlank(message = "用户名不能为空")
    @Size(min = 2, max = 20, message = "用户名长度为2-20")
    private String name;
    
    @NotBlank(message = "手机号不能为空")
    @Pattern(regexp = "^1\\d{10}$", message = "手机号格式错误")
    private String phone;
    
    @NotNull(message = "性别不能为空")
    private Integer gender;
}
```
